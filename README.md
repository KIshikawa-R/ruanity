# RUANITY GitHub Pages site

この版は、承認いただいたホームページ完成イメージを実際のレスポンシブWebページとして再構成したものです。

## 画像の差し替え
現在、住宅・建築・相談・リビング部分は画像スロットになっています。
正式な画像を `assets` に入れ、styles.css の該当クラスに `background-image:url(...)` を指定すれば差し替えできます。
AI生成した画像を使う場合も同様です。

AIRREXは、メーカーからWeb掲載用として利用可能な正式画像を受領・確認した後に差し替えてください。

Settings > Pages > Deploy from a branch > main > /(root) を選択します。
